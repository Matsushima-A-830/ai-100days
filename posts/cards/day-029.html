READMEのコマンドをそのまま打ったら動かなかった

Agent-Reach(MIT)を実機検証。GitHub issueページは素のcurlでは本文すら読めないが、CLI経由では確実に読めた。一方、READMEのコマンド例とヘルプ文言には実装との食い違いが2つ見つかった。

167件 → 件数のみ
ヘルプは「issue / PR with comments」と説明するが、実際に返るのは本文1件とコメント件数(167)のみで、コメント本文は取得できない
GitHub issueページの読み取り — 素のcurl vs Agent-Reach
✗ curl -sL .../issues/6539
<!DOCTYPE html>
<html lang="en">
<script type="importmap">
{"imports":{"react":...
(本文・コメントは含まれない)
✓ agent-reach github read <issue URL>
{"ok": true, "backend": "gh",
 "items": [{"title": "CeskaTelevize broken",
  "text": "### DO NOT REMOVE...
  (issue本文全文)"}]}
実行ログ(抜粋)
install uv tool install <GitHub Release zip> → 一発成功(クラウド実行環境では3方法ともブロック)
README agent-reach get github read ... → {"error":{"code":"BAD_INPUT","message":"unknown command or channel: get"}}
正解 agent-reach github read yt-dlp/yt-dlp → ok:true, README全文取得
youtube agent-reach youtube subtitle <id> → {"error":{"code":"RATE_LIMITED"}} (YouTube側のHTTP 429)
GitHub・V2EX・Bilibiliはログイン不要で実際に動作。追加の有料APIキー・GPUともに不要。
⚠

issue参照はowner/repo#Nのような短縮形では動かず、フルURLの指定が必要だった。クラウドの無人実行環境では3つの導入経路すべてがブロックされ、この検証はローカルPCで実施した。
