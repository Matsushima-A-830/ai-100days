日本語の指示だけでBlenderに3Dシーンを作らせてみた

mcp-for-blender(旧称blender-mcp, MIT License)をMCP経由で実際に動かし、「低ポリゴンのダンジョンシーンを作って」という日本語指示から石壁の部屋と松明を生成、レンダリング画像で確認した。

1→8
オブジェクト数。デフォルトシーン(Cube/Light/Camera計3)が、日本語指示の実行後は壁4枚+床+松明+光源+カメラの計8個に変化
execute_blender_code 実行前後のレンダリング結果
✗ Before(デフォルトシーン)
✓ After(日本語指示で生成)
blender --background を実際に試したログ
addon.py if bpy.app.background: print("cannot start server in background mode (blender -b)... run via xvfb-run -a blender")
fix nohup xvfb-run -a blender & → "BlenderMCP server started on localhost:9876"
ヘッドレス拒否はツールの意図的な仕様。エラーメッセージ自体がxvfb-run -a blenderという解決策を案内していた。後日、ローカルPCで実際のAIクライアント(Claude Code)からも同じスタックの接続・操作を確認した。
⚠

Poly Haven等のアセット取り込み、有料3D生成連携(Hyper3D/Meshy等)は未検証。実際のAIクライアントGUIからの接続体験は、ローカルPC(Windows + Blender 4.5、Claude Code)で追加検証済み(詳細はresults.md参照)。
