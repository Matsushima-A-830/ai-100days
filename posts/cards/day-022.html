金融K線専用の基盤モデルは、方向性はコイン投げ水準だった

Kronos(AAAI 2026採択、MIT)にBTC/USDTの実データで「過去400時間→未来120時間」を予測させ、実際の値動きと突き合わせた。

46.7–50%
価格が上がるか下がるかの方向性的中率(CPU/GPU、120ステップ中)。コイン投げ(50%)を明確には上回らなかった
方向性的中率の推移 — 条件を変えても50%付近から動かない
実行ログ
$ run main_run.py --device cpu / cuda:0 (lookback=400, pred_len=120)
CPU 19.62s / MAE $1928.37 / MAPE 2.33% / 方向性的中 46.7% (56/120)
GPU 2.80s(約7倍速) / MAE $1929.82 / MAPE 2.33% / 方向性的中 50.0% (60/120)
n=10 sample_count=10, 5.16s / MAE $1891.23 / 方向性的中 45.0% / 相関係数 -0.116
CPU・GPUともGPUなし・有料APIキー不要で実行可能。Kronos-miniならCPUで推論0.3秒(lookback=200, pred_len=24)。
⚠

今回はBTC/USDT・この120時間という1回・1窓の検証。MAPE 2.3%と絶対水準には近いが、方向性の的中とは別物。公式の免責通り、予測は確率的サンプルの1つであり投資判断の唯一の根拠にしてはいけない。
