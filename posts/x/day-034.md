## パターンA: 要点訴求型

AIエージェント製UIの「いかにもAI感」をLLM不要・APIキー不要で検出するOSS「impeccable」を試した。

自分の100日チャレンジのシェアカードHTML31枚を検査→94件の指摘。実体はテンプレート共通の1色のコントラスト不足で、1箇所直すと0件に。

https://github.com/pbakaus/impeccable

## パターンB: 驚き訴求型

自分が毎日作ってるシェアカードHTMLに、AIスロップ検出ツール「impeccable」をかけてみたら94件も指摘された。

内容を見たら全部同じ1つのCSS変数のコントラスト不足だった…1箇所直すだけで0件に。決定論的な検出器、ちゃんと仕事してる。

https://github.com/pbakaus/impeccable

## パターンC: 技術者向け詳細型

impeccable(Apache-2.0)の`npx impeccable detect`で自分のHTML/CSSを検査。

- 対象: posts/cards/day-003〜033.html(31枚)+共通テンプレート
- 結果: low-contrast 138件(w92/advisory46)+overused-font 2件、exit code 2
- 原因: --ink-faint(#626d80 on #161b24, 3.3:1)が全ファイル共通
- WCAG相対輝度式で色を再計算→#76839aに変更(4.51:1)→該当ファイルのfindings 2→0、exit code 2→0

ネットワーク不要・ブラウザ不要で完結。

https://github.com/pbakaus/impeccable
