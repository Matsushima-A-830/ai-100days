# Day 021 X投稿案

対象: [ahujasid/mcp-for-blender](https://github.com/ahujasid/mcp-for-blender)(MIT License、旧称blender-mcp)。
検証: MCPクライアント(自作Pythonスクリプト)→MCPサーバー→Blenderアドオン→`bpy`実行の全スタックを、Xvfb経由で実際に動かし、日本語指示から低ポリゴンの石壁の部屋+松明を生成、レンダリング画像をBefore/Afterで確認した。GPU・有料APIキー不要。

## パターンA: 要点訴求型

「MCPでAIからBlenderを操作できる」というmcp-for-blender(旧blender-mcp)を実際に動かしてみた。

日本語で「低ポリゴンのダンジョンシーンを作って」と指示するだけで、石壁の部屋+松明入りのシーンが実際に生成され、レンダリング画像で確認できた。GPU・有料APIキー不要。

https://github.com/ahujasid/mcp-for-blender

## パターンB: 驚き訴求型

Blenderをヘッドレスサーバーで動かそうとしたら`blender --background`はツール側が明示的に拒否。

でもエラーメッセージ自体に「`xvfb-run -a blender`を使え」と書いてあって、その通りにしたら普通に動いた。親切設計すぎる。

https://github.com/ahujasid/mcp-for-blender

## パターンC: 技術者向け詳細型

mcp-for-blender(MIT)を、GPUなし・有料APIキーなしのLinuxサーバー環境で全スタック検証。

- `blender --background`はアドオン側コードが`bpy.app.background`を見て意図的にサーバー起動を拒否(ヘッドレスでは動かない設計)
- `xvfb-run -a blender`でGUIモードのまま仮想ディスプレイ起動 → ソケットサーバー`localhost:9876`が正常稼働
- Python `mcp`パッケージで自作したMCPクライアントから`uv run mcp-for-blender`にstdio接続、`execute_blender_code`で日本語指示→Blender Pythonコード実行
- `get_scene_info`応答で壁4枚・床・松明・カメラの生成をテキストで確認、`bpy.ops.render.render`でBefore/After画像も取得
- 配布パッケージ版Blenderに`requests`が同梱されておらず、アドオンのmodulesパスへ直接pip installが必要だった

https://github.com/ahujasid/mcp-for-blender
