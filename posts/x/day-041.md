# Day 041 X投稿案 — milind-soni/OpenMausBot

出典: https://github.com/milind-soni/OpenMausBot

## パターン1: 要点訴求型

Grok Botの代わりに、手元のClaude Code CLIをそのままチャットのバックエンドにできるOSSアプリ「OpenMausBot」を検証。

新しいAPIキーは一切追加せず、既にログイン済みのclaude CLIを `doctor` コマンドが自動検出。ファイル作成・シェルコマンド実行・応答まで実際に動いた。

https://github.com/milind-soni/OpenMausBot

## パターン2: 驚き訴求型

「危険な操作は許可/拒否カードで確認」と説明されていたのでファイル削除を試したら、確認なしに即実行された。

セルフホストでオーナー本人として使う場合は `owner trust` でノーチェック、という実際の挙動。GUIでは違うかもしれないが、CLI経路はこうだった。

OpenMausBot: https://github.com/milind-soni/OpenMausBot

## パターン3: 技術者向け詳細型

OpenMausBot(Apache-2.0、Node24+)を `npm install` → `serve --no-open --local` でヘッドレス起動。

`openmausbot models` は27種のエンジンを一覧表示するが、このマシンで available だったのは claude の1件のみ。追加設定なしで既存ログインをそのまま検出。

`run MausBot "..."` の1往復は約2.8秒(claude-sonnet-5経由)。

https://github.com/milind-soni/OpenMausBot
