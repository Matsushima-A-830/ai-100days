## 2. 驚き訴求型

"ask todd to do the PSR for oracle"

このナゾ依頼文、メモリ無しのClaudeは「Toddって誰?PSRの意味は5つ考えられる」と
お手上げだったのに、CLAUDE.mdに1枚の対応表を置いただけで

「Todd Martinez(Finance)にOracle案件のPipeline Status Reportを頼みたいんですね、
でもパイプライン系の報告は普通Salesの仕事のはずでは?」

まで言い出した。Anthropic公式プラグイン集の記憶機能、実際に動かして検証。

出典: https://github.com/anthropics/knowledge-work-plugins

## 3. 技術者向け詳細型

knowledge-work-plugins(Anthropic公式, Apache-2.0)のproductivityプラグインを検証。

`claude plugin marketplace add anthropics/knowledge-work-plugins`
`claude plugin install productivity@knowledge-work-plugins`

の2コマンドで導入完了。memory-managementスキルはCLAUDE.mdの人物/用語/プロジェクト表を
読んで略語解読、task-managementスキルは自然文を`# Tasks`テンプレートの`TASKS.md`に変換。
いずれも.mcp.json(外部連携)無しで動作確認できた。

"friday"も実行日基準で正しい日付(2026-10-16)に変換されてたのが地味に良かった。
