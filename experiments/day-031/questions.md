# 質問セットと正解(gold answer)

検証対象論文「Memory Tax: Dissecting the Net Value of Agent Memory」
(https://huggingface.co/papers/2610.34073) の「利益(benefit)」「税(tax)」という分解を
借りて、2本の自作会話ログそれぞれに8問、計16問を用意した。

正解はトランスクリプト作成者(この検証を行っている本人)が、会話ログの内容だけから機械的に
決めたもので、以下で実装する検索(RAG相当)・メモリ(メモリ相当)のどちらの実装よりも先に
確定させてから各条件での解答に進んだ。カテゴリ区分:

- `current`: 現時点の最新の値を聞く(基本的にどちらの方式でも答えられるはずの問題)
- `historical`: 既に上書き・変更された過去の値を聞く(メモリが「現在値」しか保持しない設計だと
  失われやすい問題)
- `synthesis`: 複数ターン・複数セッションに分散した情報を集約しないと正しく答えられない問題
  (素朴な検索がtop-kの制約で全部の断片を拾えないと失敗しやすい問題)
- `niche`: 一度しか言及されない具体的な事実、または言い換えられた表現から元の事実を
  紐づける必要がある問題

## 採点方法

各条件(RAG/メモリ)の解答が、正解に含まれる本質的な情報(数値・固有名詞・日付)を
過不足なく含んでいれば正答(O)、欠落・誤りがあれば誤答(X)、部分的に正しいが抜けがある
場合は△として記録する。△は集計上は誤答(X)として扱う(甘く採点しない)。
