→ `autoindex` has no `--data-dir`. It talks to an ALREADY-RUNNING node over
  the ES-compat HTTP API via `--url` (default http://localhost:9200); the
  node itself (the bare `xerj [OPTIONS]` server-start form) is the one that
  takes `--data-dir`. Easy to confuse since both subcommands share the same
  binary and many flag names.
